## The top level idea

> Create a ecosystem which is connected in every way possible 

## The emotions of the player / What should the game invoke

- Creativity 
- Knowledge gaining
- Learning about Operating Systems
- A Zero inside of an ecosystem. you are the pray not the hunter

- Be able to use different game styles (stealth, blazing guns, using the enviroment)
- The Player **has to** use the different game styles <- this could become hard!

## The Gameplay

- Player is a Process inside of an operating system 
- Player starts from a mounted device on the operating system 
- The players goal is to survive the operating system and **corrupt the operating system**?  <- becomes more powerful with more ressources 
- Player can move around the **visualized operating system** interacting with other processes, hardware and software
- While the player is interacting with the OS the user of the OS can become suspicious of the Process and can delete it the player will have to juggle between continuing the game and keeping the detect-o-meter inside its bounds
- The Operating System itself will try to stop you disrupting the performance of the OS when the player becomes a problem
- Player will be able to reset the detect-o-meter using **hacking**
